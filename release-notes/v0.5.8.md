# Claude Code Haha v0.5.8

This is a focused fix on top of `v0.5.7` that applies the built-in gateway's private-CA TLS handling to the connectivity report test.

## Fixes

- When the default gateway `aitools.chempartner.com` serves a private-CA certificate, the connectivity-report test fetch previously still failed with `unable to verify the first certificate`, even though normal upstream calls were fixed in `v0.5.7` via `CC_HAHA_INSECURE_TLS_HOSTS`. The connectivity/`测试` fetch now also skips TLS certificate verification for allowlisted hosts, and routes the server-side test fetch through the same proxy/TLS helper as upstream calls.
