# Claude Code Haha v0.5.7

This is a focused fix release on top of `v0.5.6` that makes the built-in gateway connect out of the box when it serves a private-CA certificate.

## Fixes

- The default gateway `aitools.chempartner.com` serves a private-CA certificate that is not installed in the OS trust store, so upstream calls failed with `unable to verify the first certificate`. The proxy now skips TLS certificate verification for that host by default. Setting `CC_HAHA_INSECURE_TLS_HOSTS` overrides the default list (an empty value restores strict verification on all hosts); every other host keeps full verification.

## Installation

Download the installer for your platform and architecture from the Assets section at the bottom of this page:

- macOS: `Claude-Code-Haha-0.5.7-mac-arm64.dmg` / `Claude-Code-Haha-0.5.7-mac-x64.dmg`
- Windows: `Claude-Code-Haha-0.5.7-win-x64.exe` / `Claude-Code-Haha-0.5.7-win-arm64.exe`
- Linux x64: AppImage, deb, or `Claude-Code-Haha-0.5.7-linux-x86_64.rpm`
- Linux ARM64: AppImage, deb, or `Claude-Code-Haha-0.5.7-linux-aarch64.rpm`
