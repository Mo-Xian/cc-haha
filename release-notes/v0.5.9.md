# Claude Code Haha v0.5.9

This is a focused fix on top of `v0.5.8` that actually makes the built-in gateway's private-CA TLS bypass work under Bun — the runtime the app ships on.

## Fixes

- The private-CA TLS bypass (`unable to verify the first certificate`) was injected as an undici `dispatcher`, a Node-only mechanism. cc-haha runs on Bun, whose `fetch` ignores `dispatcher` and reads the `tls` option instead — so the connectivity report test and upstream requests still failed against `aitools.chempartner.com` when `HTTPS_PROXY` was set. The helper now emits `{ tls: { rejectUnauthorized: false } }` on Bun, so the allowlisted gateway host's certificate is skipped on every path that reuses it (connectivity test + proxy upstream).
