# Claude Code Haha v0.5.6

This is a focused release on top of `v0.5.5` that adds provider-level image recognition and fixes a gateway `400` failure when non-visual main models receive image blocks.

## New & Improved

- **Provider-level image recognition (ImageReadTool)**: the `ImageRead` tool can now be driven by a configured provider, and supports an offline describe fallback when a vision provider is unavailable.

## Fixes

- **Non-visual main models no longer hit upstream `HTTP 400` when receiving images**: image blocks attached through the SDK / VS Code / desktop array-input path (not just pasted images) are now downgraded to recognized text descriptions — or a placeholder when recognition isn't configured — before reaching a text-only gateway. A non-visual main model fallback also applies in the server proxy's `text_only` image handling, so a missed real image is omitted rather than producing a `400`.
- Fixed processing of flat-mount gateway base URLs that expose a complete endpoint without a `/v1` prefix.

# Claude Code Haha v0.5.6

这是 `v0.5.5` 之后的聚焦版本：新增按 Provider 的图片识别能力，并修复非视觉主模型接收图片时触发上游网关 `400` 的问题。

- 修复了暴露完整端点（无 `/v1` 前缀）的 flat-mount 网关 base URL 处理。
